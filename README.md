# Roze za 50

Spletna stran: šopek vrtnic, ki zacveti. Dan za Klementino.

Čisti HTML + CSS + JS, brez odvisnosti in brez build koraka.

## Lokalno
Odpri `index.html` v brskalniku (ali `npx serve`).

## Deploy (Vercel)
1. Push na GitHub.
2. Vercel -> Add New Project -> izberi repo (Framework: Other, brez build ukaza).
3. Ime projekta: `klementina50` -> `klementina50.vercel.app`.

## Kaj je kje
- `script.js`: barve in položaji vrtnic (`ROSES`), animacija, cvetni listi
- `style.css`: barve ozadja in pisava, časi animacij
- `index.html`: besedilo na dnu in podpis
